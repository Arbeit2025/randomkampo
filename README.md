# ランダム漢方（randomkampo）

ボタンを押すと、漢方薬をランダムで1件表示する小さなツールです。既存の random 系列（randomdisease など）の漢方版です。

## 使い方

- **🎲 ランダムで漢方薬を表示**：収録した全148件の処方からランダムに1件を選び、処方名と一緒に基本的な情報（読み方・構成生薬・効果・効能・体質や証の目安・出典）を表示します。
- 出典は傷寒論・金匱要略など確かなものだけを記載しています。確かでない処方は出典の記載を省略しています。
- もう一度ボタンを押すと、別の処方が表示されます。

処方の情報は、一般的な知識をこのツール用に書き起こした内蔵データから表示します（外部サイトの本文の転載はしていません）。外部通信をしなくても動作します。

> ⚠️ このツールは一般的な情報提供・学習のためのものです。診断や治療の代わりにはなりません。漢方薬にも副作用があり、体質・証に合わないものを使うと、効かないばかりか症状が悪化することもあります。実際に使うときは、自己判断せず医師・薬剤師に相談してください。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m pytest tests/
# または
python -m unittest discover -s tests
```

※ テストでは外部通信を行わず、内蔵データと画面表示を検証します。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。
